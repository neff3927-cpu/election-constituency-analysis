# 국회의원 지역구 인구와 표의 등가성 분석

Streamlit 대시보드 프로젝트입니다.

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 데이터
`data/README_data_sources.md`에 데이터 현황, 기준일, 출처를 정리했습니다. 현재 제22대 총람에서 확인 가능한 최대·최소 인구 및 계산 평균, 제22대 시·도별 의석수를 반영했습니다. 254개 선거구별 원자료 및 역대 총선 전체 분포는 아직 확보·연결되지 않아 빈 템플릿으로 두었습니다.

제23대 총선 가정은 제22대 선거구 경계를 유지하고 인구 데이터만 바꾸는 시나리오입니다.
