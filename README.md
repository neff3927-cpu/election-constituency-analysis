# 국회의원 지역구 인구와 표의 등가성 분석

Streamlit 기반 프로토타입입니다.

## 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 현재 상태
- 예시 데이터로 화면 구성 및 인터랙션 확인
- 지도는 실제 선거구 경계가 아닌 예시 좌표 마커
- 실제 데이터와 제22대 선거구 GeoJSON을 확보한 뒤 교체 필요

## GitHub / Streamlit Community Cloud
1. 이 폴더의 파일을 GitHub 저장소 루트에 업로드합니다.
2. Streamlit Community Cloud에서 저장소와 `app.py`를 지정해 배포합니다.
