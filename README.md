# 국회의원 지역구 인구와 표의 등가성 분석 — 최종 제출용 사이트 코드

## 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 대시보드 구성
- 공통 입력: 총선 시기, 시도, 선거구
- 지도: 선거구별 주민등록인구, 표의 등가성 지수, 인접 선거구 인구편차
- 차트: 차트 1·차트 2를 독립적으로 선택
- 상세정보: 선거구, 주민등록인구, 선거인수, 표의 등가성 지수, 전국 순위
- 제23대 총선: 제22대 선거구 경계를 유지하고 인구만 갱신하는 가정 분석

## 최종 확정 차트 옵션
1. 선거구별 인구 순위
2. 역대 최대·최소 인구편차 비율
3. 역대 최대·최소·평균 인구 변화
4. 인접 선거구 인구 비교
5. 표의 등가성 지수 분포
6. 총선별 지수 1 초과·미만 비율
7. 주민등록인구와 선거인수 관계
8. 선거인수 ÷ 주민등록인구 비율
9. 지역별 주민등록인구와 지역구 수 관계

요청에 따라 다음 차트는 최종 메뉴에서 제외했습니다: 역대 선거구 인구분포(Box Plot), 인구증감률과 표의 등가성 지수 관계, 지역구 1석당 주민등록인구, 선거구별 개별 표의 등가성 지수 막대그래프.

## 데이터 연결 상태 — 반드시 확인
이 ZIP에는 실제 통계 원자료가 들어 있지 않습니다. `data/` 안의 CSV는 열 이름만 준비한 입력용 템플릿입니다. 따라서 원자료를 채우기 전에는 통계 차트와 인구 색상화가 '자료 없음' 상태로 나타나는 것이 정상입니다. 가상 예시 수치를 실제 분석 결과처럼 표시하지 않도록 예시 데이터 파일과 미리보기 기능을 최종 배포본에서 제거했습니다.

## CSV 파일 규격
- `data/constituency_population.csv`: `시도,선거구,주민등록인구,선거인수,투표자수,위도,경도,지도명,이전인구`
- `data/constituency_population_23rd.csv`: 제22대와 동일한 선거구 공간범위의 제23대 가정 인구 `시도,선거구,주민등록인구,선거인수,투표자수,위도,경도,지도명,이전인구`
- `data/election_history_summary.csv`: `총선,연도,최대인구,최소인구,평균인구`
- `data/historical_constituencies.csv`: `총선,연도,시도,선거구,주민등록인구`
- `data/election_voters.csv`: `총선,시도,선거구,선거인수,투표자수`
- `data/region_population_seats.csv`: `지역,주민등록인구,지역구수`
- `data/adjacency_population.csv`: `선거구,인접선거구,선거구인구,인접선거구인구`

`지도명`은 GeoJSON 속성 `SIDO_SGG`와 정확히 일치해야 지도 색상과 통계가 연결됩니다. 이름이 일치하지 않으면 경계는 보이지만 해당 선거구의 인구 색상은 연결되지 않습니다.

## 지표 해석 주의
- 표의 등가성 지수 = 분석 대상 선거구 평균 인구 ÷ 해당 선거구 인구
- 이 지수는 주민등록인구 기준 상대지표이며 실제 투표 영향력을 직접 측정하지 않습니다.
- 선거인수는 선거권자 자료이며 주민등록인구와 모집단·기준일이 다를 수 있습니다.
- 시도별 인구와 지역구 의석수 분석은 인구비례성을 탐색하는 분석이며 법적 위법 여부를 판정하지 않습니다.
- 과거 총선 분석에는 각 총선 당시의 선거구 경계와 인구자료를 사용해야 합니다.
- 제23대 화면은 실제 확정 선거구가 아닌 제22대 경계를 유지한 가정 분석입니다.

## 지도 표시
제22대 선거구 경계는 공개 GeoJSON을 앱 실행 시 불러옵니다. 외부 타일 서버에 의존하지 않고 GeoJSON의 실제 좌표 범위에 맞춰 대한민국 선거구 경계를 표시합니다. 인터넷 연결이 필요합니다.
